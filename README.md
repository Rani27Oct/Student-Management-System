# Student Management System

This is a simple Student Management System built using HTML, CSS, and JavaScript.

## Project Overview

This project allows users to manage student records by adding, editing, deleting, and searching student details through a simple web interface. Student data is stored using Local Storage so that records remain available after refreshing the page.

## Features

* Add student details
* Display student list
* Edit student information
* Delete student records
* Search student records
* Display total student count
* Data stored using Local Storage

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Local Storage

## Future Scope

* Connect with backend using Spring Boot
* Store data in MySQL database
* Add user authentication and login
* Generate student reports

## How to Run

1. Download or clone the repository.
2. Open `index.html` in any browser (Chrome recommended).
3. Start adding student details.
